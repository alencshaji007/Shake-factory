# Shake Factory

A premium, cinematic one-page website for a milkshake brand — real
ingredient photography and hand-crafted SVG illustrations, composited
and animated with GSAP + ScrollTrigger and smooth-scrolled with Lenis,
plus a real WebGL 3D accent (Three.js) drifting behind the hero. Most
visuals are a real photograph or a hand-drawn vector illustration of
the real object; the hero's floating coffee beans/pistachios are
procedurally-modelled 3D geometry rather than a photo or a flat SVG.

## Running it locally

This is a fully static site — no build step, no dependencies to install.

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```

Or open `index.html` directly in a browser.

## About the images

This project was built in a sandboxed environment with **no outbound
network access to image hosts** — Unsplash, Pexels, Pixabay and Wikimedia
Commons are all blocked at the network level here. A Hugging Face Hub
connector was also checked for real photography: it has no studio
milkshake photo dataset, and the closest fruit-photo datasets are only
100×100px thumbnails, too low-res for a hero image.

So instead of a placeholder box or an AI-generated photorealistic render
(explicitly out of scope for this project), every image in
`assets/images/` started as an **original hand-crafted SVG illustration**
— a real strawberry/banana/milkshake *shape*, built from layered
gradients, shading, highlights and small realistic details (seeds,
ridges, a whipped-cream swirl, glass condensation), generated by
[`scripts/generate_svg_assets.py`](scripts/generate_svg_assets.py).

**Most of those illustrations have since been replaced with real
photography** supplied by the site owner — 15 real photos are in use now
(strawberries, banana, mango, blueberries, almonds, coffee beans, cashews,
pistachios, chocolate, ice cubes, milk splash, plus three full
milkshake/dessert photos in the new Showcase section). A few studio-background
photos were cleaned up with [`scripts/remove_bg.py`](scripts/remove_bg.py)
(a flood-fill color-key, not an AI tool) — one that arrived with a
checkerboard "transparency preview" baked in instead of a real alpha
channel used the [`scripts/remove_bg_checker.py`](scripts/remove_bg_checker.py)
variant of the same technique. See
[`assets/images/README.md`](assets/images/README.md) for the complete
breakdown of what's a real photo vs. what's still an illustration, and
how to swap in more — it's a one-line change per image, no code
restructuring needed.

## Structure

```
index.html                        → all markup/sections
css/style.css                     → design system + layout (palette, type, cards)
js/main.js                        → Lenis + GSAP ScrollTrigger animation timelines
js/hero3d.js                      → hero's WebGL 3D background (Three.js, ES module)
js/vendor/                        → self-hosted gsap.min.js, ScrollTrigger.min.js, lenis.min.js, three.module.min.js
assets/images/                    → all illustration assets (see README in that folder)
scripts/generate_svg_assets.py    → regenerates every SVG illustration
```

## Sections

1. **Hero** — cinematic opening: real-photo strawberries tumble through
   frame, settle back, and the real product photo reveals on a glossy
   floor, followed by the "Shake Factory" title reveal, all set against
   a real WebGL 3D field of procedurally-modelled coffee beans and
   pistachios drifting in the background (`js/hero3d.js`) — blurred and
   dimmed so it reads as atmosphere, not the main subject. Scrolling out
   parallaxes/blurs the whole stage like a camera pull-back.
2. **Ingredients** — a pinned, scroll-scrubbed depth scene: three layers of
   real ingredient photos + a couple of illustrations move at different
   speeds/rotations to simulate 3D depth without any fake 3D models, and
   every image idles with a small looping drift/rotate so the scene
   keeps feeling alive even at rest.
3. **Signature** — the flagship Strawberry Cloud shake illustration scales
   and rotates in on scroll, with floating real strawberry/cream cutouts.
4. **Collection** — six product cards, each with its *own* shake
   illustration (a distinct fill color, glass, and garnish — not one shake
   recolored six times). Cards tilt and the product image parallaxes
   opposite the cursor on hover, like studio product photography.
5. **Showcase** — "Shot, not rendered": three real photographed
   milkshake/dessert shots in a framed gallery strip, proving the site's
   authenticity claim with actual photography.
6. **Our Craft** — brand story section with 8 ingredient portrait tiles
   (mostly real photos now), each with a slow idle scale-pulse.
7. **Footer** — CTA + site links.

## Tech

- **GSAP + ScrollTrigger** for all scroll-driven timelines (vendored
  locally in `js/vendor/`, no CDN dependency).
- **Lenis** for smooth-scroll, synced to GSAP's ticker.
- Vanilla CSS (custom properties, `clamp()` fluid type, `prefers-reduced-motion`
  and `prefers-color-scheme` support) — no framework.
- Hand-authored SVG illustrations — see `scripts/generate_svg_assets.py`.
- **Three.js** (vendored in `js/vendor/three.module.min.js`, loaded as an
  ES module by `js/hero3d.js`) for the hero's real WebGL 3D background —
  procedurally-modelled coffee bean and pistachio geometry, no external
  `.glb`/model downloads. Everywhere else, depth is still simulated with
  layered CSS parallax rather than 3D. Degrades to nothing if WebGL is
  unavailable, and to a single static frame under
  `prefers-reduced-motion`.
