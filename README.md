# Shake Factory

A premium, cinematic one-page website for a milkshake brand — layered
ingredient illustrations composited and animated with GSAP + ScrollTrigger
and smooth-scrolled with Lenis. No fake 3D fruit models, no flat colored
shapes pretending to be food: every visual is a hand-crafted vector
illustration of the real object (strawberry, banana, milkshake glass…),
animated as a layer.

## Running it locally

This is a fully static site — no build step, no dependencies to install.

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```

Or open `index.html` directly in a browser.

## About the images

This project was built in a sandboxed environment with **no outbound
network access to image hosts** — Unsplash, Pexels, Pixabay and Wikimedia
Commons are all blocked at the network level here. A Hugging Face Hub
connector was also checked for real photography: it has no studio
milkshake photo dataset, and the closest fruit-photo datasets are only
100×100px thumbnails, too low-res for a hero image.

So instead of a placeholder box or an AI-generated photorealistic render
(explicitly out of scope for this project), every image in
`assets/images/` is an **original hand-crafted SVG illustration** — a
real strawberry/banana/milkshake *shape*, built from layered gradients,
shading, highlights and small realistic details (seeds, ridges, a
whipped-cream swirl, glass condensation), generated by
[`scripts/generate_svg_assets.py`](scripts/generate_svg_assets.py). See
[`assets/images/README.md`](assets/images/README.md) for the full asset
list and how to swap in real photography later if you get some — it's a
one-line change per image, no code restructuring needed.

## Structure

```
index.html                        → all markup/sections
css/style.css                     → design system + layout (palette, type, cards)
js/main.js                        → Lenis + GSAP ScrollTrigger animation timelines
js/vendor/                        → self-hosted gsap.min.js, ScrollTrigger.min.js, lenis.min.js
assets/images/                    → all illustration assets (see README in that folder)
scripts/generate_svg_assets.py    → regenerates every SVG illustration
```

## Sections

1. **Hero** — cinematic opening: ingredient illustrations fly in and
   converge, the milkshake product illustration scales up, then the
   "Shake Factory" title reveals. Scrolling out parallaxes/blurs the whole
   stage like a camera pull-back.
2. **Ingredients** — a pinned, scroll-scrubbed depth scene: three layers of
   ingredient illustrations move at different speeds/rotations to simulate
   3D depth without any fake 3D models.
3. **Signature** — the flagship Strawberry Cloud shake illustration scales
   and rotates in on scroll, with floating strawberry/cream cutouts.
4. **Collection** — six product cards, each with its *own* shake
   illustration (a distinct fill color, glass, and garnish — not one shake
   recolored six times). Cards tilt and the product image parallaxes
   opposite the cursor on hover, like studio product photography.
5. **Our Craft** — brand story section with ingredient portrait icons.
6. **Footer** — CTA + site links.

## Tech

- **GSAP + ScrollTrigger** for all scroll-driven timelines (vendored
  locally in `js/vendor/`, no CDN dependency).
- **Lenis** for smooth-scroll, synced to GSAP's ticker.
- Vanilla CSS (custom properties, `clamp()` fluid type, `prefers-reduced-motion`
  and `prefers-color-scheme` support) — no framework.
- Hand-authored SVG illustrations (no icon library, no AI image generation)
  — see `scripts/generate_svg_assets.py`.
- No Three.js/3D fruit models — depth is simulated purely with layered
  illustration parallax.
