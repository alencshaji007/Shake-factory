# Shake Factory

A premium, cinematic one-page website for a milkshake brand — real
ingredient photography composited and animated with GSAP + ScrollTrigger
and smooth-scrolled with Lenis. No 3D fruit renders, no CSS-shape food, no
cartoon assets: every visual is a photograph slot, animated as a layer.

## Running it locally

This is a fully static site — no build step, no dependencies to install.

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```

Or open `index.html` directly in a browser (smooth-scroll and some
`background-image` behavior work best served over HTTP rather than
`file://`).

## ⚠️ About the images

This project was built in a sandboxed environment with **no outbound
network access to image hosts** (Unsplash, Pexels, Pixabay, Wikimedia,
etc. are all blocked at the network level here). Real photography could
not be downloaded automatically.

Every image in `assets/images/` is therefore a **clearly-labeled
placeholder** — a soft color card with a dashed border and text like
"STRAWBERRY — real cutout photo, transparent bg" — generated by
`scripts/generate_placeholders.py`. They are deliberately *not* trying to
look like food, so there's no risk of a placeholder being mistaken for a
finished photograph.

**The entire site — HTML structure, CSS layout, and all GSAP/ScrollTrigger
animation timelines — is fully wired up and ready.** All you need to do is
drop real photographs into `assets/images/` using the exact filenames
already referenced in `index.html`. See
[`assets/images/README.md`](assets/images/README.md) for the full list of
filenames, recommended sizes, and where to source free, real, licensable
food photography (Unsplash, Pexels, Pixabay, Wikimedia Commons).

No code changes are required to swap the images — just replace the files.

## Structure

```
index.html              → all markup/sections
css/style.css            → design system + layout (palette, type, cards)
js/main.js                → Lenis + GSAP ScrollTrigger animation timelines
js/vendor/                → self-hosted gsap.min.js, ScrollTrigger.min.js, lenis.min.js
assets/images/             → all photo slots (see README in that folder)
scripts/generate_placeholders.py → regenerates the placeholder art
```

## Sections

1. **Hero** — cinematic opening: real ingredient cutouts fly in and
   converge, the real milkshake product photograph scales up, then the
   "Shake Factory" title reveals. Scrolling out parallaxes/blurs the whole
   stage like a camera pull-back.
2. **Ingredients** — a pinned, scroll-scrubbed depth scene: three layers of
   real ingredient photographs move at different speeds/rotations to
   simulate 3D depth without any fake 3D models.
3. **Signature** — the flagship Strawberry Cloud shake photograph scales
   and rotates in on scroll, with floating strawberry/cream cutouts.
4. **Collection** — six product cards, each meant to hold its *own* real
   milkshake photograph (not one shake recolored six times). Cards tilt and
   the product photo parallaxes opposite the cursor on hover, like studio
   product photography.
5. **Our Craft** — brand story section with real ingredient portrait shots.
6. **Footer** — CTA + site links.

## Tech

- **GSAP + ScrollTrigger** for all scroll-driven timelines (vendored
  locally in `js/vendor/`, no CDN dependency).
- **Lenis** for smooth-scroll, synced to GSAP's ticker.
- Vanilla CSS (custom properties, `clamp()` fluid type, `prefers-reduced-motion`
  and `prefers-color-scheme` support) — no framework.
- No Three.js/3D fruit models — depth is simulated purely with layered
  photographic parallax, exactly as the brief specifies.
