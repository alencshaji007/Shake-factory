# About these images

Every image in this folder is a **hand-crafted SVG illustration** — real
fruit/nut/shake *shapes*, built from layered gradients, shading,
highlights and detail (strawberry seeds, banana ridges, a milkshake's
whipped-cream swirl and condensation), not a labeled placeholder box and
not a stock photo.

## Why SVG instead of photographs

This project was built in a sandboxed environment with **no outbound
network access to image hosts** — Unsplash, Pexels, Pixabay and Wikimedia
Commons are all blocked at the network level here. A Hugging Face Hub
connector was also checked: it has no dataset of studio milkshake
photography, and the closest fruit-photo datasets (e.g. `fruits-360`)
are only 100×100px thumbnails — far too low-resolution for a hero image.

Rather than fall back to AI-generated photorealistic renders (explicitly
out of scope for this project) or ship a placeholder box with a filename
on it, every asset here is an original vector illustration, generated by
[`scripts/generate_svg_assets.py`](../../scripts/generate_svg_assets.py).
SVG also means every image is crisp at any size (the hero shake scales up
to fill most of the screen), loads instantly (the entire set is under
70KB total), and needs no separate mobile/retina versions.

## Swapping in real photography later

If you get real product/ingredient photography, you can drop it in
without touching the CSS or JS:

1. Save your photo (JPG/PNG/WebP, ideally with a transparent or clean
   background for the ingredient cutouts) anywhere in `assets/images/`.
2. In `index.html`, find the `<img src="assets/images/NAME.svg">` tag for
   that item and point `src` at your new file instead.
3. For the three section backgrounds (hero, signature, craft), replace
   the CSS gradient in `css/style.css` — search for `.hero__bg`,
   `.signature__bg`, `.craft__bg` — with a `background-image: url(...)`
   pointing at your photo.

## Current asset list

**Ingredient icons** — `strawberry.svg`, `banana.svg`, `mango.svg`,
`blueberries.svg`, `almonds.svg`, `cashews.svg`, `pistachios.svg`,
`hazelnuts.svg`, `chocolate.svg`, `cookie.svg`, `milk-splash.svg`,
`whipped-cream.svg`, `ice-cubes.svg` — the scroll-pinned ingredient depth
scene and the "Our Craft" section use these; `strawberry.svg` alone also
drives the hero's tumble/scatter phases.

**Product illustrations** — `shake-strawberry.svg`, `shake-chocolate.svg`,
`shake-mango.svg`, `shake-pistachio.svg`, `shake-caramel.svg`,
`shake-cookie.svg` — each is its own tapered-glass illustration with a
flavour-matched fill gradient, whipped cream, straw, and a distinct
garnish (fresh strawberry, chocolate shavings, mango wedge, crushed
pistachio, caramel drizzle + nuts, or cookie crumble) so the six shakes
read as six different products, not one glass recolored six times.

**Hero-only assets** — `bottle.svg` (a labeled glass milk-bottle, used
alongside `shake-strawberry.svg`'s glass in the hero's product reveal)
and `splash-ring.svg` (the two-tone fruit/cream pour-ring transition
between the tumble and product-reveal phases). Both were designed to
match the composition of a reference product-ad video the user supplied
for this project.

## Regenerating or editing the illustrations

```
python3 scripts/generate_svg_assets.py
```

All shapes, gradients and colors are defined in that one script — edit
the relevant `gen_*()` function (ingredients) or the `garnish_*()` /
`build_shake()` calls (products) and re-run it to regenerate every SVG.
